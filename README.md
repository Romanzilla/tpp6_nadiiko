## Реалізовані частини у `main.cpp`
1. **Частина 1 (`runPart1`)** — відтворення стану гонитви (*Race Condition*) для $N = 18$ ($180\,000$ ітерацій на потік) та усунення помилки через `std::mutex` і `std::atomic<int>` із вимірюванням часу через `std::chrono::steady_clock`.
2. **Частина 2 (`runPart2Deadlock`, `runPart2Fixed`)** — відтворення взаємного блокування через C++20 `std::barrier` (режим `--deadlock`) та два способи усунення дедлоку (`std::scoped_lock` і єдиний порядок блокування `mutexA -> mutexB`).
3. **Частина 3 (`runPart3`)** — модель *Producer-Consumer* для моніторингу погодних станцій (Варіант 18): 12 пакетів метеоданих (опади, вітер, тиск), два потоки-споживачі з `std::condition_variable` та виявлення аномалій.
4. **Частина 4 (`runPart4`)** — послідовне та паралельне (`std::async(std::launch::async)` + `std::future`) поелементне множення двох векторів із сумою результатів для $N \in \{10^6, 10^7, 5\cdot 10^7\}$ і кількості задач $k \in \{2, 4, 8\}$.
